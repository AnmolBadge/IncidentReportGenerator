# 📌 Project Overview

**Incident Report Generator** is a command-line Python tool that walks the user through a guided incident-response questionnaire and automatically generates a professional, formatted incident report document.

Instead of manually typing up an incident report from scratch, the tool asks the user structured questions about the incident — type, affected systems, timeline of events, indicators of compromise, and remediation steps — and compiles the answers into a clean, ready-to-share PDF or Word document.

This project was developed to understand and demonstrate the practical implementation of cybersecurity documentation and incident-response workflows using Python. It serves as a learning project and is intended for educational purposes only.

# ⚙️ Features

- Guided Q&A: walks the user through incident type, date, and systems affected.
- Timeline entry builder — add incident events with timestamps.
- IOC (Indicator of Compromise) collection section — suspicious IPs, domains, URLs, file hashes.
- Containment and remediation steps capture.
- Export the finished report to PDF or Word (.docx) document.
